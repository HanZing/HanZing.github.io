## 📁 Projects

### 🧩 VulnEye – Client-Side Web Security Scanner [![VulnEye](https://img.shields.io/badge/VulnEye-000000?style=for-the-badge&logo=github&logoColor=white)](https://github.com/HanZing/vuln)
*JavaScript, Chrome Extension APIs, HTML/CSS*
- Built a Chrome extension that scans any webpage across six security checks: vulnerable JavaScript libraries, XSS-prone patterns, HTTP security headers, CSRF protection, Content Security Policy and third-party trackers.
- Matched loaded scripts against known-vulnerable library versions (retire.js data) and identified trackers from a 44,000-domain list, with OWASP-referenced severity ratings and suggested fixes.
- Combined results into a weighted 0–100 security score with exportable PDF reports, scan history, a domain whitelist and per-scanner settings.

### 📊 AssetOps – IT Asset Management Dashboard [![AssetOps](https://img.shields.io/badge/AssetOps-000000?style=for-the-badge&logo=github&logoColor=white)](https://github.com/HanZing/asset-ops)
*Vue.js, Nuxt.js, TypeScript, Pinia, Chart.js*
- Built a dashboard for tracking laptops, servers, monitors and software licenses, with summary metrics for assigned, available and retired assets and overall utilization.
- Implemented add, edit and delete, search, filtering by type and status, and per-asset detail pages using a typed Pinia store, reusable components and a filtering composable.
- Visualized inventory by type and status with Chart.js charts that update as asset data changes.

### 🚗 CarSim – Used Car Marketplace [![CarSim](https://img.shields.io/badge/CarSim-000000?style=for-the-badge&logo=github&logoColor=white)](https://github.com/HanZing/CarSim)
*PHP, MySQL, JavaScript, Python · University software engineering project*
- Developed a role-based web application for admins, buyers, sellers and agents using a Boundary–Control–Entity architecture.
- Implemented registration and login with hashed passwords, admin tools to create, search and suspend user accounts and profiles, car listings, buyer shortlists, agent ratings and reviews, and a loan calculator.
- Accessed MySQL through parameterized PDO queries and wrote Python scripts to generate test data and automate login tests for each user role.
